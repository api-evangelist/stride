# Stride

> Stride is a multichain liquid staking protocol built as a Cosmos SDK appchain (chain-id `stride-1`) secured by Cosmos Hub interchain security. Users stake tokens (ATOM, TIA, DYDX, OSMO, and 10+ others) and receive liquid staking receipt tokens (e.g. stATOM, stTIA) that keep accruing staking rewards while remaining usable across DeFi. Stride's machine-readable interface is the Cosmos SDK gRPC/REST (LCD) query surface plus IBC, wrapped by the official stridejs SDK — it does not publish a REST OpenAPI.

## Overview
- Category: Crypto / Web3 — liquid staking, Cosmos ecosystem
- Chain: Cosmos SDK appchain, chain-id `stride-1`, IBC-connected, Hyperlane bridge
- Backed by: Multicoin Capital
